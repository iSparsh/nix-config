# Hosts

- [asus-nixos](asus-nixos/README.md): Intel server laptop, user `sparsh`, shared profiles plus Jellyfin/Immich.

Add the workstation with its own generated hardware file when it migrates to NixOS.
See [adding a machine](../docs/architecture.md#adding-a-machine). Hardware files use
ordinary `.nix` names; only the host declaration uses `.mod.nix`.
